# Pure Water Tracker for Purenish

## 🌟 開発の経緯
本アプリは、開発者が日頃からお世話になっている**BeautifulCars（ビューティフルカーズ）の村上社長**にご相談し、ご意見を伺いながら最初に開発した専用アプリです。グリーンライフ社製「ピュアニッシュ」の仕様に基づき設計されています。

## ⚠️ 重要：汎用版（General Edition）への移行推奨
本アプリは開発の原点ですが、現在は**「純水器業界全体の可視化とデータの適正化」**という大きな目的を掲げ、**汎用版（General Edition）**の開発と普及に全力を注いでいます。

より詳細な分析や、他環境との比較、今後のデータ還元計画に参加いただくためにも、特別な理由がない限りは以下の**汎用版**をご利用いただくことを強く推奨いたします。
